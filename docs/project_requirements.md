# Smart Irrigation Advisor

## Objective
Predict whether irrigation is required based on weather, crop, and soil data.

## Inputs
- Temperature
- Humidity
- Rainfall Forecast
- Wind Speed
- Pressure
- Soil Type
- Crop Type
- Crop Age
- Land Area
- Previous Rainfall
- Month

## Outputs
- Irrigation Required (Yes/No)
- Water Required (Liters)
- Pump Running Time (Hours)

## Notifications
- WhatsApp via Meta Cloud API
